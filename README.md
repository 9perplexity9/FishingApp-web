# html/ — веб-приложение + PWA (главная версия)

Открывается где угодно: ПК, телефон, планшет. Файлы: `index.html` (разметка+стили), `app.js` (логика),
`data.js` (120 мест по 6 областям), `data_guide.js` (способы ловли, рыбы, правила погоды),
`leaflet.js` + `markercluster.js` (карта), `sw.js` (офлайн-кэш), `manifest.webmanifest` (PWA-манифест).

`mosty_rybalka.html` — старая версия только про Мосты, оставлена как архив.

## Как установить как приложение (бесплатно, без App Store)

Нужен http/https (через file:// установка PWA недоступна):

**ПК (Windows/Linux)**
```bash
cd html && python3 -m http.server 8080
```
Открой `http://localhost:8080/index.html` в Chrome → значок «Установить» в адресной строке.

**Android (Chrome)**
1. Выложи все файлы папки `html/` на любой https-хостинг (GitHub Pages, Netlify Drop — просто перетащить файлы).
2. Открой страницу в Chrome → меню ⋮ → «Добавить на главный экран» / «Установить приложение».
3. Готово — иконка на экране, полноэкранный режим, офлайн.

**iPhone/iPad (Safari)**
1. Выложи все файлы папки `html/` на https-хостинг.
2. Открой страницу в Safari → Поделиться → «На экран "Домой"».
3. Готово — приложение с иконкой, полноэкранный режим, офлайн-кэш.

Прогноз погоды и геокодинг требуют интернета; карта мест, шпаргалки и рейтинги работают офлайн.
